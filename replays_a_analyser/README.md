# Replays à analyser

Déposez ici un replay (`.replay`) pour lequel Pirate Tracker a donné un mauvais nombre de coffres,
en indiquant dans le message d'envoi combien de coffres vous avez réellement ouverts ou cassés.

Où trouver vos replays : `%LOCALAPPDATA%\FortniteGame\Saved\Demos\` (collez ce chemin dans la barre
d'adresse de l'Explorateur Windows). Le plus récent correspond à votre dernière partie.

Envoi depuis le site GitHub : **Add file → Upload files**, glissez le fichier, puis
**Commit changes** (limite : 25 Mo par fichier).
